Questions

Does PluckIt upload my images?

No. It has no network entitlement, so the sandbox blocks every connection. Recognition runs on your Mac.

Which Macs does it run on?

Any Mac on macOS 26 or later. It needs Vision's document recognition.

How do I install it?

Clone the source from GitHub and run scripts/build.sh --install. It compiles the app, signs it ad hoc and copies it to Applications.

Do I need a paid developer account?

No. macOS only blocks apps that arrive from the internet. An app you build on your own Mac opens normally.

Will it stop working after seven days?

No. That limit applies to free provisioning profiles on iOS devices, not to Mac apps signed ad hoc.

What format is the text in?

Headings, paragraphs, lists, tables, barcodes and QR codes come back as Markdown. The Output picker switches between Markdown, plain text and Automatic, which uses Markdown only when the page has structure.

What does Clean Up fix?

Join Lines, Join Hyphenated Line Breaks, Remove Newlines, Remove Spaces, Collapse Spaces, Trim Line Whitespace and Remove Empty Lines. You can undo each one, and Restore Original Text brings back the untouched extraction.

Why does macOS ask for permissions again after a rebuild?

Each rebuild makes a new signature, so macOS treats it as a new app.
